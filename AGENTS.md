# Application development

This repository contains RunbookOps. Course lessons and exercises live in TrainWithShubham/agentic-ai-for-devops on v2.

Use uv and the committed lockfile. Keep commits short and omit co-author trailers. Do not push, create a PR, or provision AWS resources unless requested.

Write plainly. Keep technical names descriptive; Gada Electronics and its sample identities are fictional demo data. Do not claim production readiness or live verification without evidence.

Never commit .env, .state, tokens, credentials, or private signing material. Never silently fall back to paid inference. Offline practice must be labeled. Preserve access filters, exact-change approval, restart/resume, and idempotency.

Run meaningful tests and retain the 100% Python and JavaScript application coverage gates. Record architecture choices, failures, fixes, and verification limits in DECISIONS.md.
